# Jazz Bass Walking Line Generator
コード進行（ii-V-I等）を組み立てるとウォーキングベースラインを自動生成しWeb Audio APIで再生するジャズベースツール。
## Features
- 16種類のジャズコードからドラッグ&クリックで最大8コードのプログレッションを構築
- ルート・5度・コードトーン・クロマチックアプローチノートを組み合わせたウォーキングライン自動生成
- Web Audio API（三角波+ローパスフィルター）でベース音を再生
- BPMスライダー（60-200）でテンポ調整
- ループモード対応・再生中のノートをリアルタイムハイライト表示
## Usage
コードパレットからコードをクリックしてプログレッションを組み立て「Generate & Play」を押すと生成・再生が始まる。
